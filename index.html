技术栈：Spring Boot、MySQL、Redis、Lua、Kafka、Caffeine、MyBatis-Plus

项目细节：
  • 使用 Redis + Lua 保证秒杀库存扣减与防重操作的原子性：编写 Lua 脚本原子执行库存校验与一人一单判断，再扣减库存并记录用户，消除竞态条件，防止超卖。
  • 基于 Spring Task 实现订单超时自动关闭，完善状态机：定时扫描超时未支付订单，批量更新为已取消并回退库存，避免重复处理，保障订单闭环。
  • 采用逻辑过期与空值缓存分别解决击穿和穿透问题：缓存值中封装过期时间字段，超时异步更新并返回旧数据；空结果写短 TTL，拦截穿透请求。
  • 构建 Caffeine + Redis 多级缓存：L1 Caffeine 本地缓存 + L2 Redis，读先本地再 Redis、命中回填，写时失效两级缓存，减少对 Redis 的访问压力。
  • 通过 Redis + AOP 注解实现滑动窗口限流，支持多维度防刷：自定义注解，AOP 切面用 Redis ZADD 记录请求、ZREMRANGEBYSCORE 清理过期、ZCARD 统计，超出阈值则限流。
